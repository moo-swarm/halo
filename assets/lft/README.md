# LFT Foro Teatro — логотип

| Файл | Для чего |
|---|---|
| `lft-logo-1024.png`, `lft-logo-512.png` | Статичная аватарка Telegram (канал / группа / бот) |
| `lft-animation.mp4` | Видео-аватарка Telegram: 800×800, 9,6 с, зацикливается |
| `lft-animation.gif` | Превью анимации |
| `lft-logo.svg` | Векторный логотип |
| `lft-logo-animation.html` | Исходник: открыть в браузере, чтобы посмотреть вживую |

Анимация: между L и FT по очереди появляется буква, и получается слово:

- **LIFT** («поднять»; поднимают занавес): I падает сверху с отскоком в луче прожектора и улетает обратно вверх.
- **LEFT** (stage left, левая кулиса): E растёт снизу, перекладины выезжают слева; потом буква уходит влево.
- **LOFT** (колосниковая, fly loft): O сжимается из большого круга, как диафрагма прожектора, и уходит, вращаясь монеткой.

Красная стрелка над промежутком в статичном логотипе показывает, куда встаёт буква.

Пересобрать все файлы: `node scripts/build-lft-logo.js` (нужны playwright и ffmpeg).
