# LFT Foro Teatro — логотип

| Файл | Для чего |
|---|---|
| `lft-logo-1024.png`, `lft-logo-512.png` | Статичная аватарка Telegram (канал / группа / бот), только буквы LFT, без подписи |
| `lft-animation.mp4` | Видео-аватарка Telegram: 800×800, 9,8 с, зацикливается |
| `lft-animation.gif` | Превью анимации |
| `lft-logo.svg` | Векторный логотип |
| `lft-logo-animation.html` | Исходник: открыть в браузере, чтобы посмотреть вживую |

Анимация: между L и FT по очереди появляется буква, и получается слово. У каждой буквы свой цвет и свой способ появиться:

- **LIFT** («поднять»; поднимают занавес): красная I падает сверху с отскоком в луче прожектора и улетает обратно вверх.
- **LEFT** (stage left, левая кулиса): золотая E растёт снизу, перекладины выезжают слева; потом буква уходит влево.
- **LOFT** (колосниковая, fly loft): розовая O сжимается из большого круга, как диафрагма прожектора, и уходит, вращаясь монеткой.
- **LUFT** (нем. «воздух»): голубая U плавно опускается, покачиваясь, как пёрышко, а потом её сдувает.

Красная стрелка над промежутком в статичном логотипе показывает, куда встаёт буква.

Пересобрать все файлы: `node scripts/build-lft-logo.js` (нужны playwright и ffmpeg).
